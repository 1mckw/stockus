# stockus

NDX100 / DJI30 日線掃描器：四點成線趨勢線、Creek / Ice、平行通道，可存 Chartpack。

## 本機執行

```bash
python server.py
```

瀏覽器開啟 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)

- `server.py`：靜態頁面、Yahoo 圖表代理、Nasdaq 成分股、Chartpack 存檔
- `ndx100-scanner.html`：掃描與圖表 UI（含手機版面）
